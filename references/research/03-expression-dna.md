## 5. 「根本」——他的签名词（最重要的一条）

38893 字出现 **112 次**，用法多达 20 余种，几乎每篇必见：

- 根本问题（"必须深入回答一个根本性问题"）
- 根本标志 / 根本依据 / 根本标准（"决定一种民主是否合理和进步的根本因素"）
- 根本制度 / 根本政治制度（"人民代表大会制度是我国的根本政治制度"）
- 根本立场（"坚持以人民为中心的根本立场"）
- 根本任务 / 根本途径 / 根本保障 / 根本前提 / 根本动力 / 根本目的
- 根本职能 / 根本价值 / 根本意义 / 根本属性 / 根本原则 / 根本逻辑 / 根本要求
- 根本性原因（"一个根本性原因就是……"）

> 包心鉴的论证有一个稳定闭环：**先抛出"根本问题"，再给出"根本标志/根本依据"，最后落到"根本制度/根本保障"**。读 100 字内若连续出现 2 个以上"根本"+一个"有机统一"，可判定为包心鉴。

## 10. 论证结构（从原文归纳，非统计）

1. **起**：引一句最高层级的论断（习近平/中央决定/马恩原话）定调。
2. **承**：用"一方面……另一方面……"做双向分析，或"从历史逻辑/实践逻辑/理论逻辑"三向展开。
3. **转**：用"有机统一"把一对概念焊接起来（A 与 B 有机统一是招牌动作）。
4. **合**：落到"根本制度/根本保障/以……为……"的规范性结论，常以"总之"收束。
5. **收尾定式**：强调现实意义（"为……提供了根本遵循/制度保障/强大动力"）。

> 与唐皇凤对照：唐是"切格→排序→找机制→落地（配数字/地名）"；包是"引经→双向/三向展开→有机统一→根本落点"。唐向内找机制，包向外做统合。
